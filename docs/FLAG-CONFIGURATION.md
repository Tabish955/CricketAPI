# Feed flag configuration

The feed alone supplies flagUrl. Clients must not construct these URLs.
This is the exact build configuration, not proof every URL passed GET. Only
URLs passing the existing HTTPS/HTTP200/image MIME/204800-byte harness are
emitted. West Indies and its variants always remain null (multi-country).
No member-country or Caribbean-community substitution is configured.

Explicit full-name and abbreviation aliases expand to A, XI, Women, U19,
and combined women/U19/A/XI variants. There is no country substring inference.
Unknown identities remain null and are reported, not silently classified as national.
England, Scotland and Wales use subdivision flags, not the UK flag.

## Verification artifacts

`flag-coverage.json` records every configured code with status/MIME/measured
bytes, the complete cb/live/recent/upcoming non-null flag inventory, null
inventory with reasons, and the observed Indonesia live sample. The build
prints each as FLAG_CODE, FLAG_SUPPLIED, FLAG_NULL and IDN_LIVE_SAMPLE.
A mapped national team missing a validated flag blocks the build.
If Indonesia is not in the current live window, IDN_LIVE_OBSERVED is zero;
that is reported honestly, not replaced with a fixture.

This change does not modify imageUrl policy, scores/teamId, response schema
or JSON cache headers. Production stays unchanged until review and merge.
